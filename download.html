Installing, start to finish

  1. 01

    Run the file

    Open Sentinel-Setup.exe from wherever your browser saved it. When Windows warns you, choose More info, then Run anyway.

  2. 02

    Go through the installer

    The suggested answers are fine. Sentinel opens at the end and puts its mask in your system tray. It starts with your computer unless you turn that off in the tray menu, and it updates itself, so you only do this once.

  3. 03

    Press Start scanning

    One button in Live protection, or Scan with beside the browser you use. No sign-up: the app makes an account for this computer by itself, and you can sign in later to see your history on other devices.

  4. 04

    Browse normally

    A small island in the corner of your browser shows Sentinel is watching. Search, and a mark appears beside the results. It only works while the browser is in front of you, and private windows leave no trace in Sentinel.

Is this the real file?

Choose the file you downloaded. Your browser works out its fingerprint, called a SHA-256, and compares it with the one GitHub recorded for this release. The file stays on your computer: nothing is uploaded.

Every change in this version

File scans

  • A file result now says how much of the file Sentinel looked at: all of it, part of it or none of it. It never shows green for a file it did not fully check.
  • A digital signature no longer turns a warning green.
  • An archive Sentinel cannot open now says so instead of looking safe.

Pricing

  • Plans are now one sheet, with each limit shown once.
  • Nothing is on sale yet, so the only button is Start free.

Download page

  • It shows the Windows warning you will see when you first run the installer, and lets you practise getting past it.
  • It checks that your download is the real file, without uploading it.
  • The release notes on the page come straight from the changelog.

Home page on phones

  • It shows Sentinel's full name, the mask in a gold arch and the Download button on the first screen.
  • On a computer, reduced motion no longer covers the name.

Is this call a scam

  • It is now a public page at /call that works without an account and keeps your place. The old address in the app takes you there.
  • It never says a call is fine, and it tells you to wait or use another phone before you call back.

Signing in

  • The sign-in pages are rebuilt around the real mask, with fields you can see.
  • If you are already signed in, you go straight to the app.
  • Sign in with Google only shows when it works.

The galaxy

  • An enlarged galaxy card no longer vanishes on slow computers.

Not on Windows

Mac, Linux and phones

There is no Sentinel app for these yet. The web app has the manual scans, and you can install it like an app from your browser’s address bar.

The optional browser add-on

Where the app’s live scanning is not available, the add-on puts masks on search results from inside the browser, and pairs with a running Sentinel. Its password alarm works on any computer: it stops you typing a protected password into a site that is not the real one. Turn it on in the add-on’s options.

It is not in the browser stores, so you load it by hand. In Chrome, Edge or Brave: unzip it, open the browser’s extensions page, turn on Developer mode and choose Load unpacked. In Firefox it loads as a temporary add-on from about:debugging and is gone when Firefox closes.
